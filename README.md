# Arabuluculuk Asistanı — güncelleme paketleri

Bu depo, Arabuluculuk Asistanı programının imzalı güncelleme paketlerini barındırır. Program yeni sürümleri kendisi bulur ve kurar.
İlk kurulum için **Releases** sayfasındaki `ArabuluculukAsistani-Kurulum-*.zip` dosyasını indirip bir klasöre çıkarın ve `Baslat.exe` ile açın.

Kişisel veri (taraf bilgileri, tutanaklar) bu depoda ve paketlerde bulunmaz; kullanıcının bilgisayarında kalır.
